ไลฟ์ขายของ TikTok LIVE

ปักตะกร้าทีละชิ้นตามเวลา → AI พูดเรื่องชิ้นที่ปักอยู่ · จบรอบเขียนบทใหม่เอง ไม่ซ้ำของเดิม (จำทุกประโยคที่เคยพูด)

1. สินค้าในไลฟ์ (เรียงตามลำดับที่จะปัก)

#ชื่อสินค้า (ให้ AI พูด)คำที่ใช้หาในหน้าไลฟ์ราคาจุดเด่น / ข้อมูล / โปรที่มีจริงนาทีคลิปของชิ้นนี้
"คำที่ใช้หา" = ชื่อสั้น ๆ ที่ตรงกับในรายการสินค้าของไลฟ์ (ว่าง = ใช้ชื่อสินค้า) · นาทีว่าง = ใช้ค่ากลาง

2. ตั้งค่า

คลิกขวาที่ปุ่มพื้นหลัง/คนขาย = เอาออก · ไม่มีคลิปคนขาย = ตอน AI พูดโชว์รูปสินค้าตัวใหญ่แทน · การ์ดตะกร้ามีเลขโชว์ตลอดตามชิ้นที่ปัก

ก่อนเริ่ม: เปิดไลฟ์ใน LIVE Studio + เพิ่มสินค้าเข้าไลฟ์ให้ครบ · ล็อกอิน TikTok ในหน้า Chrome ที่บอทเปิด · ใน LIVE Studio เพิ่มแหล่งภาพ "จับหน้าต่าง" = KNF LIVE และแหล่งเสียงจากคอม

ลำดับต่อชิ้น: ปักตะกร้าชิ้นนั้น → เล่นคลิปของชิ้นนั้น → AI พูดคั่นบนการ์ดสินค้า → คลิปถัดไป … ครบนาทีแล้วไปชิ้นถัดไป · ชิ้นไหนไม่มีคลิป AI พูดยาวทั้งช่วง · ใส่ 0 = เล่นคลิปอย่างเดียว
